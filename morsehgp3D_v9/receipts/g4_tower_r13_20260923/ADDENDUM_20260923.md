# Addendum : lecture des temps d'appareil de R13 (contrelectures B et C)

23 septembre 2026. Le reçu reste tel quel ; cet addendum en précise la
lecture après les contrelectures de B et C.

- **`certificate_device_ms`** (189 ms à 08/000000/K5) est l'intervalle
  CUDA upload + noyau + download de l'appel, **pas** le coût du noyau seul.
  La sonde v18 ne publie pas `kernel_ms` ; la ligne « Coût du noyau S3 »
  du README doit se lire « coût de l'appel sur l'appareil ».
- **1 504 warps** : c'est le nombre lancé d'après la requête d'occupation,
  pas un taux d'occupation mesuré.
- **Attribution** : le gain de S3 **dans R13** est de 138 ms à K5 et
  583 ms à K10 (filtre GPU seul contre S2 + S3). Les écarts R12 → R13
  (−6 à −13 %) mêlent le préchauffage et S3, sur deux sessions. En R12,
  la paire répétée variait de 3,9 %.
- **Juge** : actif dans les deux préflights (55 523 décisions, 3 404
  mises en attente), inactif sur les cas LiDAR.
- **Cas GPU** : neuf cas ont une phase observée sur l'appareil ; sept ont
  les certificats S3, deux le seul filtre S2.
