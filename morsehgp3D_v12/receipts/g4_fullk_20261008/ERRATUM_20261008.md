# Erratum du reçu de la session K (8 octobre 2026)

Le [README](README.md) de ce reçu reste inchangé (reçu immuable) ; cette note corrige une phrase de sa lecture de
`MES-D6`, relevée par l'auditeur Codex dans son
[contre-rejeu strict](../audit_reponses_20261008/d6_session_k/README.md) et dans la cellule de `CST-0207`.

**Phrase fautive** : « des coordonnées qui remplissent 32 bits (grille de 1/2048 mm) triplent le coût du catalogue
CPU ». Le message du commit `8dc5d6b16` dit de même « full 32-bit coordinates x2.9 ».

**Correction** : la dilatation ×2048 multiplie par 2048 des coordonnées déjà quantifiées au millimètre. Les trames
ng00–02 tenant dans 18 bits (le cas ×8 est admis au profil 21), les coordonnées dilatées restent sous $2^{29}$ : elles
ne remplissent pas 32 bits. C'est une homothétie d'entiers, sans détail physique nouveau. Le constat chiffré reste
valable pour ce qu'il mesure : à ×2048, le catalogue CPU au profil 32 coûte 2,90 à 2,95 fois celui du couple
(21, ×1), parce que toutes les feuilles quittent la voie native étroite (`leaves_narrow=0`) pour la voie exacte. Le
coût de coordonnées qui occuperaient vraiment 32 bits n'est pas mesuré ; le seuil produit de D6 reste ouvert.
