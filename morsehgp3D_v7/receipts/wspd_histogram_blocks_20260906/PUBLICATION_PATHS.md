# Chemin du plan historique

La copie `prototype/PLAN.md` contenait un lien relatif au répertoire privé
de préparation. Ses octets sont conservés exactement dans `PLAN.md.txt`,
pour ne pas la présenter comme une page de navigation du dossier publié.
Le certificat actif reste lié dans le README du paquet.

Les premiers `publication.json` et `SHA256SUMS` sont conservés avec le
suffixe `.original`. Le manifeste de copie courant change seulement la
destination de ce plan ; son origine et son hash restent inchangés.
Le nouveau manifeste de sommes couvre aussi ces deux originaux et cette
note. Aucun résultat, source ou journal d'exécution n'est réécrit.
