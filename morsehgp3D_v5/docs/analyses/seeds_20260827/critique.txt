### Incohérence majeure entre rapports

Le rapport math montre qu'un test O(22 évaluations) par ancre retire 92,6 % des seeds à 8000 (et le commit concurrent `d76f502c` : 93,1 % à 4000 par secteurs) ; le rapport de mesure établit que le coût est le **nombre de seeds** (mise en forme + `is_acute_seed`), pas le scan. La conception device attaque pourtant les 18,2 G seeds **sans aucun test d'ancre dans son étage hôte** (§ 3.1) et compare son estimation (8–14 s) à une lane CPU de 94 s qui n'existe plus : avec W3 + secteurs, la lane CPU q3 à 48 fils est probablement à ~10–20 s (plancher covers ≈ 14 s + 7 % des seeds), soit l'ordre de grandeur du device. Le gain GPU sur q3 n'est plus démontré ; il doit être re-mesuré contre la **nouvelle** lane CPU avant d'écrire un kernel.

Deux fixtures (`w3_vs_sect`) :

## 2. Formules corrigées / complétées

1. Rapport math § 3.1 : avec `u = −0,9D·e`, `v = (D/√12)·e` : `4u·v = −3,6/√12 · D² = −1,039 D²`, `q = −0,19 D²`, `f = −0,849 D² < 0` (conclusion inchangée ; `−0,52 D²` serait `2u·v`).
2. « ~38 % des sites jamais intérieurs » : 36 % sur `eight_clusters` (1403 − 874 − 20,5 − 2), ~24 % sur `uniform` et `terrain`.
3. Lemme 4.1, à ajouter : `J = D²(3G − 2EX) = G(D² − 8|v3|²) ≥ G·D²/3 > 0` pour tout seed aigu ⟹ `Jb < 0` inatteignable.
4. Identité de signe V5 (prouvée, 2 953 tétraèdres aléatoires, 0 échec) : pour `y` non coplanaire (`B(y) ≠ 0`), `sign q4_power(f4, z) = sign(B(y)) · sign(P(z)·B(y) − P(y)·B(z))` ; largeurs `|P| < 2^103`, `|B| < 2^52` ⟹ produits < 2^156 (U192 suffit).
5. Test cellulaire, cas d'égalité (V3) : `k` strict (`f > 0` aux 4 sommets ⟹ `f > 0` sur la cellule fermée, min d'une affine aux sommets) et `c` strict (`f > 0` en un point de la cellule fermée ⟹ `f > 0` en un sommet, max aux sommets) sont tous deux **exacts** ; `f ≥ 0` n'est pas nécessaire. Cas limite de la localisation : si `D²·A1/12` est un carré parfait et le seed équilatéral, `⌊Gr·α/â⌋ = Gr` sort de `[−Gr, Gr[` : écrêter (fail-closed).
6. Largeurs cellulaires : `|N|² = G·D²·(EX−G) < 2^168` ⟹ `|N| < 2^84` ; `|N·E2| < 2^119,2`, `×16 < 2^123,2` ; `2G·b̂ < 2^117,6` — i128 tient pour Gr ≤ 16, pas au-delà.
7. Pente des seeds `eight_clusters` : exposant effectif 1,7 (2k→50k), pas 1,9.
8. Rapport de mesure, formule W3 avec `w = z − m` : `4|w|² − D² < −4|w_⊥|·D/√3` (facteur `4/√3`, composante perpendiculaire) — équivalent à `A < 0 ∧ 3A² > 4|W×d|²`.
9. Test par secteurs (K = 8) ⊉ W3 : témoins universels sur le disque fermé mais pas sur les sommets du polygone (exemple : `z = (1000+e, 550, 0)`, demi-plan `v_y > −634`, disque de rayon 577, sommets du polygone à ~800).
