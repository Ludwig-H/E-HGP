# Captures avant correction des provenances

Ces deux suites de 21 tests passent, y compris la nouvelle fixture
axiale additive. Ensuite l'auditeur a signalé deux omissions dans les
reçus appariés : mélange possible de builds/machines dans un résumé,
et marqueur de checksum axial non contrôlé par le validateur. Le moteur
C++ ne change pas ; les correctifs et mutants des outils Python sont
requalifiés dans les captures finales du dossier parent. Aucun mélange
de mesures du constructeur ni défaut géométrique n'est constaté ici.
