# Prototypes Phase 15 obsolètes

Ce répertoire conserve cinq fichiers de travail datés du 3 août 2026. Ils
étaient présents hors suivi Git dans les répertoires actifs, sans cible CMake
ni validation ouvrant une autorité exacte. Leur présence sous `include/`,
`src/` et `tests/` pouvait néanmoins laisser croire à une API ou à un jalon
livré.

Ces fichiers sont des instantanés historiques uniquement : ils ne sont ni
compilés, ni installés, ni exécutés par la suite de tests. Ils ne doivent pas
servir de repli au chemin produit et ne portent aucun statut public `exact`.
Leur arborescence d'origine est conservée sous ce répertoire afin de faciliter
une éventuelle analyse historique.
