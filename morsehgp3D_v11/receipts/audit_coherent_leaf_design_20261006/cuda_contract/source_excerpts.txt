580: **Proposition, à contester avant écriture : la feuille cohérente.** Le warp entier parcourt le même préfixe, avec un
581: contrôle de flux uniforme.
582: - Les étapes scalaires (centre, faces J2, `lines_possible`) sont calculées de façon redondante par toutes les lanes :
583:   même instruction, aucune divergence.
584: - Recensement : la lane i juge le site i (`side` en i128), puis `__ballot_sync` donne les masques intérieur et
585:   coquille.
586: - Support canonique : les triplets et quadruplets de la coquille sont répartis sur les lanes, et le premier succès, dans
587:   l'ordre, est le plus petit indice gagnant (ballot puis `ffs`).
588: - Émission par la lane 0, ou listes écrites en parallèle.

590: **Questions.**
591: 1. Le recensement séquentiel s'arrête au seuil (`p == threshold`), et `census_tests` compte les sites visités
592:    jusque-là. Je propose de calculer tous les sites, puis de déduire le compteur du rang du seuil-ième intérieur dans
593:    l'ordre (popc d'un préfixe de masque). De même, `judged` et les compteurs du support canonique se déduiraient de
594:    l'indice du premier succès. Voyez-vous un compteur dont la valeur dépendrait d'un calcul fait **après** l'arrêt
595:    séquentiel, en particulier un refus `kUnresolved` qu'un site au-delà du seuil lèverait dans la version parallèle
596:    mais jamais dans la séquentielle ? Je propose d'ignorer les refus des sites au-delà du point d'arrêt séquentiel.
597: 2. Même question pour la recherche du support canonique : un refus non certifié au-delà du premier succès doit-il être
598:    ignoré ?
599: 3. Quels mutants exigez-vous ? Je propose : seuil décalé d'un site, refus au-delà de l'arrêt non ignoré, premier
600:    succès pris au plus grand indice, ballot partiel (masque de lanes incomplet).

114: MHGP11_LEAF_HD bool q3_global_power(i128 d, const i128* n) {
115:   const i128 d_limit = i128(1) << (123 - 2 * kBits), n_limit = i128(1) << (124 - kBits);

125: // Signe de D|z-a|^2 - 2N.(z-a) ; faux si la voie native n'est pas certifiee (leaf.cpp prendrait checked/Wide).
126: MHGP11_LEAF_HD bool side(const Center& c, const u32* z, int& out) {
127:   if (!native_power_ok(c)) return false;
128:   const i64 v0 = i64(z[0]) - c.anchor[0], v1 = i64(z[1]) - c.anchor[1], v2 = i64(z[2]) - c.anchor[2];
129:   i128 total = c.d * i128(v0 * v0 + v1 * v1 + v2 * v2);
130:   total += c.n[0] * (-2 * i128(v0));
131:   total += c.n[1] * (-2 * i128(v1));
132:   total += c.n[2] * (-2 * i128(v2));
133:   out = sign(total);
134:   return true;
143: // center_orientation, voie native certifiee seulement.
144: MHGP11_LEAF_HD bool center_orientation(const u32* a, const u32* b, const u32* c, const Center& s, int& out) {
145:   if (!s.orient) return false;
146:   const Vec normal = cross(diff(b, a), diff(c, a));
147:   i128 total = 0;
148:   for (int j = 0; j < 3; ++j) {
149:     const i128 coordinate = s.n[j] + s.d * i128(s.anchor[j] - i64(a[j]));
150:     total += coordinate * normal.v[j];
151:   }
152:   out = sign(total);
153:   return true;
