## 2. Synthèse transverse

### 2.a Résultats mathématiques établis (recopiés)

**Certificat de fenêtre k-NN (exact, reçu comme sous-source).**
`δ_out(a)² = min_{x ∈ X∖({a}∪W_M(a))} ||x−a||²` (coupure au **premier omis**) ;
`4R² < δ_out(a)² ⟹ X∩B ⊆ {a}∪W_M(a)` — couvre `S`, `I_B` et **tout** le shell `U_B`. Inégalité stricte, fail-open à l'égalité. Chemin rapide entier `i64` (Jung) : `3·diam(S)² < 2·δ_out(a)² ⟹ 4R² < δ_out(a)²`. Statut : `exact_window_certified_subsource` — jamais source complète. L'owner ne filtre pas avant certification (fixture `M=2`).

**Jung / compacité par positivité.** Pour un support propre positif `S` (centre dans `conv(S)`) : `R ≤ diam(S)·√(3/8)`, `diam(S) ≥ R√(8/3)`, `diam(S) ≤ 2R`, `B ⊆ ball(a, 2R)` pour tout `a ∈ S`.

**Cœur commun WSPD/Jung (fondement du pipeline V4).** Blocs `A ⊆ B(c_A,r_A)`, `B ⊆ B(c_B,r_B)`, `S=r_A+r_B`, `d=||c_B−c_A||`, `m_0=(c_A+c_B)/2`. Épaisseur minimale de la circumboule autour du milieu de l'arête maximale : `D/(2√3)` (q3), `(√3−1)D/(2√2)` (q4), toutes deux `> D/4`. **Si `d > 3S`** : `R_AB=(d−3S)/4 > 0` et `B°(m_0, R_AB) ⊆ B°(c_U, ρ_U)` pour tout support admissible `U` d'arête maximale `ab`, `a∈A, b∈B`. Fermeture du bloc : `h = smax+1−q` `PointId` distincts strictement intérieurs dans le cœur (8 pour q4, 9 pour q3, 10 pour q2 à `smax=11`). WSPD Callahan–Kosaraju : `O(n)` blocs à séparation fixe, chaque paire couverte exactement une fois ; **la WSPD ne garantit pas `d>3S` par elle-même** — un bloc à `d≤3S` a un cœur de rayon nul et reste fail-open ; le test exact `d_lb > 3S_ub` est l'autorité.

**Seuil de mort universel.** Pour tuer la candidature d'arête maximale d'un support de cardinal `q` : `h = smax+1−q` témoins à `PointId` distincts (union sur tous les crédits, héritage compris).

**Spindle exact.** Formulation `(e,t)` : `e=z−a`, `t=b−z`, `H=e·t`, `E=||e||²`, `X=||t||²` : q2 `H>0` ; q3 `H>0 ∧ 4H²>EX` ; q4 `H>0 ∧ 3H²>EX` ; masque imbriqué `q4⇒q3⇒q2` ; égalités jamais créditées. Formulation `(d,s)` : `H=Dr(cosγ−t)`, `R=D²r²sin²γ` : q4 `H>0 ∧ 2H²>R`, q3 `H>0 ∧ 3H²>R`. Largeurs u16 : `E,X,|H| < 2^34` ; comparaisons finales ≤70 bits (`i128` CPU / deux limbs u64 device).

**SOC64 (lemme).** `Ebox=C−A`, `Tbox=B−C` ; le prédicat est séparément convexe (cône de Lorentz) sur `Ebox×Tbox` ; si les `8×8=64` couples de coins passent une lane, tout `A×B×C` la passe ; l'échec reste `UNKNOWN` (contre-fixture à marge fictive −7 vs 217 réelle).

**CORNER512 (théorème).** Le domaine des triples admissibles est séparément convexe en `a,b,z` ; le produit continu des trois AABB est `ALL` ⟺ les `8³=512` triples de coins passent. Un coin échouant peut être fictif : guide un split, jamais `NONE`.

**LP1 (théorème du LP projectif).** `κ_G(d)=min{Σα_i·q_i : Σα_i·s_i=d, α_i≥0}` (`q_i=||s_i||²`, `D=||d||²`) : `G` couvre toute sphère par `a,b` ⟺ `d ∈ cone(G)` et `κ_G(d) < D` ; l'égalité reste ouverte. Optimum basique ≤3 coefficients → tout crédit directionnel a un certificat de ≤3 `PointId`. Oracle récursif complet de multiplicité : q4 ≤ `(3^8−1)/2 = 3280` LP, q3 ≤ 9841, q2 ≤ 29524.

**Groupes coniques.** Si `d ∈ cone{s_i}` et `d·s_i > ||s_i||²` ∀i : `Σλ_iμ_i(t) > 0` → au moins un membre intérieur à toute sphère par `a,b` (le membre dépend de la sphère). Borne trois par Carathéodory conique en 3D.

**Cutoffs 432 sous-cônes.** Dans une cellule : `cos²γ ≥ 9/11`, `sin²γ ≤ 2/11`. Cutoffs radiaux entiers : q4 `25r² ≤ 9D²` ; q3 `64r² ≤ 25D²`. Facteurs de hauteur : q2 `τ(d)≥2τ(s)`, q3 `3τ(d)≥8τ(s)`, q4 `8τ(d)≥23τ(s)`. Six constantes de cellule `k_j ∈ {11,14,17,19,22,27}` (`M_j=k_j/9`). Table directe `(L,B,P,C)` par type ; certificat q4 : `xP−yB>0 ∧ 2(xP−yB)² > Cx²` (q3 : coefficient 3) ; seuils uniformes de `11/6` (U00) à `3/2` (U22). Dominance : `F_q(a,j)=3τ_j(z_h)−2τ_j(a)` ; `O(n log⁴n + R_dir)` ; fusion `OR`/`AND` par `RectId`, `M_q = Σ_{i<j}|A_i∩B_j||B_i∩A_j|`.

**Crédits cellulaires.** `m_C(s)=min_j r_j·s` ; activation exacte `X_s = floor(T·||s||²/m_C(s)) + 1` (le `+1` indispensable) ; `C ⊆ cone(G) ⟺ r_j/(w·r_j) ∈ conv{s/(w·s)}` ; crédit = union des carriers des trois rayons, 3–9 IDs. Extension bloc d'ancres : `r ∈ cone(G−a) ⟺ ∃t>0 : a+tr ∈ conv(G)` ; recertification aux 8 coins par formes de Cramer affines en `a` ; forme fusionnée concave `F_{z,j}(a)=x_0·r_j·(z−a)−T||z−a||²`. Minorant bilinéaire de référence : `(b−a)·(z−a)−||z−a||² = (z−a)·(b−z)` ⟹ `L_z(A,B) = Σ_i min (z_i−a_i)(b_i−z_i) > 0` = H2-ALL en 12 produits/ID ; `L_z ≤ 0` = `UNKNOWN`, jamais `NONE`.

**Inversion locale.** `z ∈ int B(a+t,||t||) ⟺ t·y_z > 1/2` avec `y_z = s_z/||s_z||²` (stockage homogène entier). Support de cardinal `q` = flat de dim `4−q` dans l'espace des centres ; **injection, pas bijection** (extraire le minimum de norme du flat). `D_K` étoilé par rapport à zéro → walk du 1-squelette shallow complet en position simple ; Clarkson–Shor : `O(M(K+1)²)` sommets ; walk simple `O(M²(K+1)²)` ; Agarwal et al. `O(Mk²+M log³M)` espéré.

**Filtre FP certifié.** `F_c = cH² − E2·X2` (`c=4` q3, `c=3` q4) ; erreurs binary64 majorées `368 618`/`294 895` ; bande `B=2^19` : `f>B`/`f<−B` certifient le signe, `|f|≤B` → exact.

**Négatifs établis.** Pas de Yao d'ordre `k` : K-Gabriel littéral sur facettes → `Ω(m²)` (corollaire de Chazelle et al., `V_0=(K−1)m²+2m`) ; degré q2 par chambre non borné (fixture 13 partenaires, une chambre, zéro cosphère) ; `canon(x−a) ≠ canon(x)−canon(a)` (pas de quotient d'index) ; AABB 4D lifté ne domine pas les extrema quadratiques 3D ; `|I_B|+|S|≤smax ⇏ |I_B|+|U_B|≤smax` (shell `Θ(n)` possible) ; fold ≠ DSU de points (fixture `S={0,1,2}/T={0,3,4}`, jointure correcte `|S∩T|≥k`).

**Largeurs arithmétiques u16 (à graver).** Spindle : 70 bits. Clé de sphère q3/q4 : numérateurs jusqu'à 81 bits, `den²` 134 bits, `N²` ~162 bits, juge Gram `96·M^10` ≈167 bits → **`i128` insuffisant même pour l'oracle** ; former la clé avant l'explosion (`A=den, B=−2N, C=2N·p−den||p||²`). LP : formes `F` ~87 bits, constructeur ~137 bits, tris de rayons de cages ~240 bits. Crédits cellulaires : tout en `i64` (< `2^51`). Tie-break hull degré 4 : déborde `i64` (`7,38e19`).

### 2.e Ce que la V4 doit conserver / éviter absolument

**Conserver (le socle validé, directement aligné avec la feuille de route V4) :**
1. Le renversement génératif : chercher les supports par leur **arête maximale**, jamais éliminer des paires. La WSPD Callahan–Kosaraju comme partition exacte des paires (`O(n)` blocs) est déjà validée par les audits comme cadre — avec le test `d_lb > 3S_ub` en autorité exacte, pas la convention de séparation.

3. Pour le résiduel `A×B` : le **dual-tree fail-open** avec `L_z(A,B)` (12 produits/ID), les formes de Cramer affines aux 8 coins (crédits par bloc d'ancres = préfiguration exacte des `h_a/h_b`), SOC64/CORNER512 pour `ALL`, majorants/minorants certifiés pour `NONE` — jamais le quadratique `A×B`, jamais les extrema de coins comme `NONE`.

7. Les régimes : uniforme ET amas (les deux qualifient), terrain comme falsificateur ; l'objet est output-linéaire (~480 supports/point Poisson) — c'est la route qui doit le devenir.

**Éviter absolument :**
1. Toute boucle sur les paires ou par endpoint, tout catalogue `Θ(n²)` (même « temporaire »), toute liste `W_M` résidente, toute matérialisation de supports (fold streamé = condition d'existence à grande échelle).
2. Confondre masse sémantique (peut être quadratique, reste factorisée) et volume physique (soumis aux pentes) ; promouvoir `MIXED` en `NONE` ; créditer une égalité ; compenser un cœur vide par un verdict négatif (tout échec de certificat est fail-open, résiduel normal ≠ `unsupported_degeneracy` ≠ `resource_exhausted`).
3. Les identités implicites : index dense ≠ `PointId` ; `GenerationRank` n'est jamais une identité scientifique ; `canon(x−a) ≠ canon(x)−canon(a)`.
4. Les verts creux : juge corrélé au sujet, mutant auto-tué, `PASS_REGULAR_EXPRESSION` sans porte à code, complétude par comptage de lignes, planchers vacués, seuil `smax` figé, benchmark sous contention, une famille pour cinq, pente d'un seul compteur.
5. Le census par support (avant RLE), le DSU de points, la perturbation comme sémantique (une cosphère exacte porte un shell réel ; refus explicite), la troncature silencieuse sous cap (refus atomique ou continuation, jamais un préfixe).
6. Croire que `p+q≤smax` borne le shell `|U_B|` ou le degré local (13 partenaires/chambre ; shell `Θ(n)`) : la fenêtre `M` est un choix diagnostique, le dépassement un régime nominal.

## Questions ouvertes / ambiguïtés

1. **Le prix transitif du résiduel n'est mesuré nulle part.** Aucun audit ne chiffre `M3/M4`, le coût du census à l'échelle, les BallKeys uniques ni le fold sur une rampe : toutes les pentes portent sur `sum E4` (candidats du certificateur central). Le « chiffre manquant le plus dangereux » (coût du census BallKey-first, dixit Claude) reste inconnu à la fin de la tranche.
2. **Aucune des trois voies collectives (dominance 432 / groupes coniques / WSPD-cœur+relation-tree) n'a été départagée** : la gate `counter-only` commune est spécifiée (univers commun, même ELF, bitsets au petit `n`) mais jamais exécutée dans cette tranche. La V4 choisit la WSPD : les audits la valident comme partition mais notent qu'elle n'a « aucun claim sparse universel » (deux amas sans point au milieu → bloc entier au résiduel) et que le cœur est vide à 98,74 % sur `eight_clusters` — la V4 doit donc préciser son étage suivant pour les blocs à cœur vide (les audits proposent : L_z/dual-tree, SOC64, LP, groupes coniques).
3. **Ambiguïté de constantes du spindle** entre les deux paramétrisations : `(H,E,X)` donne q3 `4H²>EX` / q4 `3H²>EX` ; `(H,R)` donne q4 `2H²>R` / q3 `3H²>R`. Les deux sont présentées comme exactes dans leurs conventions respectives ; la V4 doit fixer une convention unique et graver les fixtures de frontière.
4. **`h_a/h_b` (témoins dans A et dans B) de la feuille V4** : la tranche contient la recertification par blocs d'ancres (8 coins, formes affines) et le `r_AB=(β−α)/(ζ_h−α)`, mais pas de théorème nommé « h_a témoins dans A » — le raccord exact entre la formulation V4 et ces briques est à écrire (probablement via les crédits par bloc + `L_z`).
5. **La condition « troisième témoin x formant un triangle aigu » (q3 V4)** : les audits mentionnent « owner-edge × carrier aigu » et que tout triangle obtus est éliminé (famille deux-droites), mais aucun document de cette tranche ne donne le théorème complet arête-maximale-q3 ⟺ triangle aigu + condition de profondeur ; il est vraisemblablement dans d'autres audits (12 août) ou dans le manuscrit.
6. **Statut du pending `terrain`** : les pentes rouges sont robustes aux continuations (encadrement `[1,533 ; 1,537]`), mais aucune valeur finale n'a jamais été calculée (`pending=0` jamais atteint sur cette famille à profondeur 4).
7. **`eight_clusters` du probe vs « mélange équilibré de huit amas » du plan** : l'auditeur exige un manifeste reliant la famille du probe à la définition enregistrée ; ce raccord n'est pas fait dans la tranche — la portée exacte du NO-GO sur la famille contractuelle reste conditionnelle.
8. **Owner half-open des frontières de cellules/cônes** : exigé partout (dominance, crédits, WSPD), avec le rappel qu'une dominance faible dupliquerait les crédits, mais aucun codage canonique complet des strates (arêtes/sommets coniques, zéro signé) n'est reçu.
9. **Politique de la cosphère lourde** : les trois options (multiplicité lossless / quotient saturé / refus `unsupported_degeneracy`) restent ouvertes ; le profil courant refuse, le `SphereRun` rend le choix réversible, mais le choix final « change le layout de sortie » et n'est pas tranché. La V4 devra décider avant de figer son format d'événement.
10. **Événements « GPU-friendly » de la V4** : les audits fournissent les briques (count-scan-fill, SoA, deux limbs, bitonic, fronts persistants, caps atomiques) mais aucun kernel CUDA n'a jamais été exécuté dans toute la tranche — le G4 n'a servi que d'hôte CPU. Tout chiffrage GPU de la V4 part de zéro mesure.
11. **Contrat V4 vs contrat v3** : la feuille V4 vise `K=10 en <100 ms` et des dizaines de millions de points ; la tranche montre que le contrat 50 k/100 ms était jugé hors de portée du nombre de tâches actuel (0,83–3,33 To/s) — la V4 doit donc établir que son nombre d'événements après WSPD+témoins est proche de la sortie (~480n) avant tout budget temps.
