### 1.2 `CONTRE_AUDIT_A617_PROFONDEUR_FRONTIERE_PAIRFRAME_20260816.md` (auditeur)

- `refine_depth_max` compte des itérations successives de résolution de frontière, pas une profondeur : la valeur `100` à `n=120` ne prouve aucune profondeur structurale. Borne réelle du radix-LBVH u16 (Karras, `wf_delta(i,j) = clz(MortonKey_i xor MortonKey_j)`, 48 bits utiles + tie-break d'index sur 16 bits sous `n <= 65535`) : **profondeur interne ≤ 48+16 = 64, feuille ≤ 65**, indépendamment de la géométrie.

- Le sélecteur vectoriel courant (rescan complet + `erase` au milieu) coûte `Σ_t Θ(F_t)`, potentiellement `Θ(n²)` par état ; `refine_steps` ne le borne pas. Compteurs causaux exigés : `selector_frontier_scan_items`, `selector_vector_moves`, `child_classifications`, `terminal_checks`.
- Scheduler à buckets recommandé : `bucket(C) = floor(log2(population(C))) ∈ {0..15}`, masque 16 bits, sélection = `highest_set_bit(nonempty_bucket_mask)` en O(1) ; coût scheduler `O(spans ouverts + 16)` par état ; formes CPU (`std::array<std::vector,16>` en pile) et GPU (files par bucket, `count -> scan -> fill`).
- `continuation_mass` n'est pas une continuation : aucun objet sérialisable, aucun run repris comparé. ABI minimale `CoreContinuation {rect_id, a_node, b_node, lane, threshold, lower_open_sat, mixed_frontier, relation_frontier, policy, epoch}` ; gate obligatoire : `capped run + resumes == uncapped run` avec `cap_hits > 0` forcé (`--target-frontier-cap=1/2`).
- Gates G1–G5 (profondeur structurale ≠ itérations ; masse ≠ nombre de spans ; contre-famille de travail ; coût du sélecteur ; cap atteint + reprise). Deux commentaires obsolètes « profondeur gouvernée par le SEUIL » à retirer du code. Interdiction de continuer à polir le scheduler ternaire historique : il reste un oracle de transition.

### 1.3 `NOTE_AUDITEUR_LBVH_SPARSE_Q3_Q4_APRES_53815F_20260816.md` (auditeur)

Masques par nœud : `DEPTH_ONLY / APEX_POSSIBLE / APEX_ALL / OUTSIDE`. Le cover est une antichaîne de nœuds, construit **une fois par arête**, partagé entre seeds.
- Axe q4 (`Q4SeedAxisTopR4`) : centres `c(τ) = a + (W + τ·n)/(2G)`, `2τ² <= T2` ; puissance `P_z(τ) = A_z - τ B_z`, `A_z = G||z-a||² - W·(z-a)`, `B_z = n·(z-a)`, racine `ρ_z = A_z/B_z`. On ne veut que les `k = 8-p` premières racines `B>0` et dernières `B<0` (p = permanents), avec toutes les égalités.
- Bornes exactes par nœud : `B_z` affine → `B_lo/B_hi` exacts par signe de `n_i` ; `A_z` séparable, `A_z = Σ_i [G s_i² - W_i s_i]`, minimum entier à l'un des deux entiers voisins de `W_i/(2G)` clippés ; comparaisons en `BigInt<4>`. Permanents : `SeedCoreQuarter` (`4·max_Z ||v(z)||² <= D G²`, `v(z)=2G(z-a)-W`), et `SeedJungPermanent16` (huit coins aux deux bouts : correct car pour un bout fixé `P_z(τ)` est **convexe en z**, son maximum est atteint à un coin).

Le prune `NO_ROOT_ALL_POSITIVE` est **retiré du v0**. Prune sûr contre seuil courant : `A_z/B_z >= A_*/B_* ⟺ F_*(z) = B_* A_z - A_* B_z >= 0`, minimum entier séparable exact ; `min F_* > 0` → prune, `= 0` → égalité possible, descendre.

## 2. Synthèse transverse

### 2.a Résultats mathématiques établis

1. **Prédicats de base** (arête owner `e=(a,b)`, site `x/z`) : `D=|a-b|²`, `E=|a-x|²`, `X=|b-x|²`, `Φ=(a-x)·(b-x)`, `H=-Φ=(x-a)·(b-x)`, `Δ_E=D-E`, `Δ_X=D-X`. Porteur aigu : `Δ_E >= 0 ∧ Δ_X >= 0 ∧ Φ > 0` (soit `H < 0` + lentille). Fuseau `W_2(a,b) = {Φ < 0} = B(m,|ab|/2)` ouverte ; shell `= {Φ = 0}` ; `W_3, W_4 ⊂ W_2` avec conditions strictes `4H² > EX` (q3), `3H² > EX` (q4), toujours **avec test de signe `H > 0` avant le carré**. Cœur et carriers sont **géométriquement disjoints**, séparés par le shell.
2. **Séparabilité par axe** : `Φ`, `Δ_E`, `Δ_X` sont des sommes de termes par axe ; les extrema sur `A×B×C` sont exacts en O(1) (candidats : 24 pour `Φ_max`, 12 pour `Φ_min`, 2 pour chaque `Δ`), corrélation par `a_k` préservée. Vérifié exhaustivement sur 6000 triplets d'intervalles.
3. **Théorème du masque endpoint** (q2, étendu q3/q4) : si `C` recouvre `A` (ou `B`), `p ∈ A∩C` donne le triplet `(a=p,b,z=p)` avec `Φ = 0` (resp. `H = 0`), donc `Φ_max >= 0` : le span n'est jamais `ALL`. La stricte porte le non-crédit ; la **conservation + replay** reste un mécanisme obligatoire.
4. **Théorème de monotonie sous raffinement** (`decide_stable_sous_raffinement`, commit `d80c4a2`) : `DEAD_*` (conditions en maxima) et `ALL_STRICT` (conditions en minima) sont stables sous restriction de `A/B` ⟹ la frontière `C` et le ledger s'héritent ; seuls `MIXED`/`MIXED_ENDPOINT` se rejouent.
5. **Ledger de cœur** : `lower <= N_q(p) <= upper` pour toute paire du bloc ; `lower >= h_q → PRUNED`, `upper < h_q → CORE_CLEAR` ; `upper - lower < h_q` n'est PAS une décision (contre-exemple `h=8, lower=7, upper=8`). Saturer `lower` est sûr ; saturer `upper` de façon incrémentale est un bug de **sûreté** — le majorant est dérivé : `upper_open_sat() = min(h_q, lower_open_sat + frontier_candidate_mass_exact)`.
6. **`CORE_CLEAR ≠ LIVE_EXACT`** pour q3/q4 ; le shell de `W_q` (q≥3) n'appartient pas au contrat (frontière angulaire `qH² = EX`, pas `Power_B = 0`) ; q2 est la seule lane où fuseau = miniboule du support. ABI : `CoreDepthLedger` q3/q4 = `{lower_open, upper_open}` ; `BallCensusLedger` (support fixé) = `{I_B, U_B}`.
7. **Plancher quadratique du cap** : partition exacte des paires + terminaux `|A|,|B| <= c` ⟹ `#R >= C(n,2)/c² = Ω(n²)` ; cap de produit `|A||B| <= C` ⟹ `#R >= C(n,2)/C`. Indépendant du nuage, de la dimension, de la séparation.
8. **Callahan–Kosaraju** : taille `O(s^d n)`, construction `O(n log n + s^d n)` ; la borne vaut pour un octree comprimé ; l'arbre radix binaire (aspect 2–4) ne dégrade que d'une constante (`<= 8^d`) ; séparation sur boîte serrée termine plus tôt (borne a fortiori). Régime atteint seulement pour `n ≳ 8000` (avant : plafond `C(n,2)`).
9. **k-NN incomplet** : le rang de voisinage d'une arête q2-vivante n'est pas borné (deux contre-exemples : droite avec 1000 points d'un côté ; demi-espace opposé). Aucun seuil sur `|ab|` seul. Certificat exact : `(a,b) q2-morte ⟺ r_{h_2}(m) <= |ab|/2`, `m = (a+b)/2` — à factoriser par blocs (région contenue dans toutes les boules diamétrales du rectangle = rôle du cœur universel).
10. **Jung / q4 axial** : `R² <= 3D/8`, `||c-m||² <= D/8` ⟹ tous les sites pertinents dans `||2z-a-b||² <= 4D`, les sommets dans la lentille ⟹ `<= 3D`. Paramétrage `c(τ) = a + (W+τn)/(2G)`, `P_z(τ) = A_z - τB_z`, top-k `k = 8-p` sur les racines `ρ = A_z/B_z` ; prune exact corrélé `F_*(z) = B_*A_z - A_*B_z` ; **coins d'AABB : maximum négatif certifiable (convexité), minimum positif NON** — prune positif retiré du v0. Le cœur de Jung est fait d'**intérieurs permanents** (mort à 8), il ne génère jamais l'apex (facteur `32/3` sur le tétraèdre régulier).
11. **Carriers par ancre vivante** : `O(h)` en espérance sous Poisson homogène (constante `29,335` par paire vivante à `h_4=8`, ratio lentille/W4 `= 10,86`), `Θ(n)` au pire cas (fixture annulaire : 632 porteurs, 0 témoin W2/W3/W4).

13. Seuils : `h_2 = 10` (tests q2), `r_4 = 8` (q4 rejette au 8e intérieur), q3 rejette au 9e.

### 2.d Pistes fermées dans cette tranche

1. **Énumérer les carriers depuis tous les triangles aigus** (objet cubique) — la source doit porter la conjonction vivacité × carrier au niveau bloc.
2. **Gateway/ledger depuis la racine** — inerte par construction ; l'amorçage est le rectangle WSPD séparé.
3. **`(A,B)` librement scindable avec redescente de C depuis la racine** (exposant 4,73) ET **`(A,B)` strictement figé** (47,7–65,9 % de paires résiduelles) — aucun seul ; la sortie est l'héritage de la frontière C (théorème de monotonie).
4. **`upper - lower < h_q` comme condition d'arrêt** — réfutée par contre-exemple.
5. **`upper_closed` / shell dans le cœur q3/q4** — hors contrat ; le shell vit dans `BallCensusLedger` d'un support fixé (q2 = seule coïncidence).
6. **Look-ahead exhaustif des trois splits** — refusé pour la v0.
7. **Source k-NN / seuil de distance pour q2** — incomplète sans hypothèse (Ahlfors/Delone hors contrat) ; contre-exemples gravés.
8. **Cap de population/masse dans le critère terminal de la partition** — plancher `Ω(n²)` prouvé ; le cap vit dans le scheduler.
9. **Scission WSPD par population** — retire la preuve de packing ; scission par diamètre/cellule canonique.
10. **Census q2 global comme route produit** — fallback/oracle seulement ; route = frontière `SHELL_POSSIBLE`.
11. **Digest d'élision comme source d'IDs** — intégrité seulement ; jamais substitut de `carrier_enumeration_root`.
12. **Poids fixe par lane comme preuve de ressource** — ordonne une file, ne certifie rien.
13. **Prune positif par les 8 coins (`NO_ROOT_ALL_POSITIVE`)** — retiré du v0 (minimum convexe possiblement intérieur).
14. **Requête « quatrième voisin euclidien » pour l'apex q4** — l'ordre utile est celui des racines axiales.
15. **Sélecteur vectoriel (rescan + erase)** — potentiellement quadratique ; conservé uniquement comme terme de comparaison.
16. **Optimiser encore le scheduler ternaire historique** — interdit ; il reste un oracle de transition.
17. **Buffers GPU dimensionnés sur la moyenne des carriers** — le max croît linéairement (110/222/430) ; cap déclaré + débordement.

### 2.e Ce que la V4 doit conserver / éviter absolument

**Conserver (acquis directement réutilisables) :**
- Le **WSPD pur** comme tronc : terminal = séparation seule, scission par diamètre/cellule canonique, `RectId` immuable exact-once ; les faits chiffrés de la campagne (constante `s³ = 512` à s=8 ; dépendance `s^1,5` aux tailles d'intérêt ; régime linéaire seulement à `n ≳ 8000` ; rect/pt par famille). Pour la V4 (s = 6/8/10), le choix de `s` est un pur arbitrage de coût, à mesurer sur `rectangles × raffinement`.
- Les **extrema séparables exacts O(1)** de `Φ/Δ_E/Δ_X` sur trois AABB — la primitive de tous les classifieurs de bloc.
- Le **théorème de monotonie/héritage** : c'est LA réponse au dilemme figer/scinder — les preuves `DEAD`/`ALL`/`NONE` d'un dual-tree s'héritent, seuls les indécis se rejouent. Directement applicable au « h_a/h_b via dual-tree, jamais quadratique » de la feuille de route V4.
- Le **ledger `lower/upper` ouvert** avec ses règles (décisions `lower >= h_q` / `upper < h_q` seulement ; majorant dérivé jamais stocké ; masque endpoint = stricte + conservation/replay ; masse relationnelle typée dans `upper`).
- La **disjonction cœur/carrier** : les témoins de zone cœur (côté `H>0`) et les carriers x/y (côté `H<0`) vivent dans des domaines opposés — la V4 doit maintenir deux domaines d'énumération indépendants (l'équivalent de `carrier_enumeration_root`), avec gates G11–G13 et la fixture annulaire 632/0.
- La **route q4** : conjonction vivacité×carrier au niveau bloc, cover de Jung par arête (`4D`/`3D`) partagé, top-k de racines axiales par branch-and-bound LBVH (`A_lo/A_hi`, `B_lo/B_hi`, prune `F_*`, permanents par coins pour les maxima seulement), CTA par arête, cap par seed + débordement, égalités jamais tronquées.
- L'**appareillage de preuve** : juge par identités `(EdgeKey, PointId)` avec 4 quantités séparées, juge de partition exact-once indépendant, mutants causaux (dont ceux invisibles aux juges de résultat : `shell-jete`, `upper-sature-incremental`), planchers anti-vacuité, témoins négatifs (`two_lines`), portes à code de sortie exact, continuations typées fail-closed (préflight complet, domaines de handles séparés, types tagués), reprise croisée entre politiques.
- La discipline **scheduler** : buckets log2, maintenance incrémentale, `count → preflight → scan → fill → validate → publish`, un compteur par unité physique nommée, caps par division.
- Le **certificat de mort au milieu** `r_{h_2}(m) <= |ab|/2` (équivalence) comme base théorique de « l'élimination rapide par h témoins dans la zone cœur » de la V4 — factorisé par blocs (région commune à toutes les boules diamétrales du rectangle), jamais par requête ponctuelle par paire.

**Éviter absolument :**
- Toute **fuite de cap de ressource dans une définition géométrique** (partition, WSPD, terminal) — plancher `Ω(n²)` mécanique. Le débordement rend `PENDING_RESOURCE`/continuation, il ne redécoupe jamais.
- Toute structure **aveugle à la sortie** sans le second étage : `10^7` rectangles pour `~2n` arêtes vivantes est le sur-coût mesuré que la V4 doit attaquer par un prune métrique de bloc — c'est exactement sa raison d'être.
- **Mesurer des pentes sous `n = 8000`**, extrapoler des moyennes, dimensionner sur des moyennes (max des carriers linéaire), lire un compteur agrégé (`noeuds`) comme critère de réception.
- Transformer une **borne en espérance en borne déterministe** (le motif d'erreur récurrent de la campagne, quatre occurrences documentées).
- Confondre `NONE` du cœur et `NONE` de la lane ; jeter le shell (`Φ_min = 0`) ; élever `H` au carré sans test de signe ; matérialiser `PairId`/triples avant la conjonction de vivacité.
- Le **profil u16 avec tie-break 16 bits borne `n <= 65 535`** : incompatible avec les « dizaines de millions de points » de la V4 — l'encodage Morton/tie-break, la borne de profondeur 64 et le refus `n hors profil` doivent être re-conçus, et la question linéaire vs `n log n` du front WSPD (indécidable sous u16) se reposera aux vraies échelles.
- Les juges `O(n³)` hors du rôle d'oracle borné (≤ 400 points ici) ; à l'échelle : invariants globaux + juge d'échantillon (déjà pratiqué dans la campagne 8k–32k).

## Questions ouvertes / ambiguïtés

1. **Le levier central n'est pas résolu dans cette tranche** : comment fermer un rectangle WSPD entier par un certificat de mort métrique de bloc (minorant de `|ab|` sur `A×B` + majorant de `r_{h_2}` sur le segment joignant les boîtes, ou range-count sur le cœur commun) ? La question est posée deux fois (fin de 1.10, Q2/Q3 de 1.7), l'auditeur pointe « le cœur universel W2 et les boules intérieures déjà développées » (1.12 § 9) mais aucun certificat de bloc n'est spécifié ni mesuré ici. C'est exactement « l'élimination rapide par h témoins dans la zone cœur » de la feuille de route V4.
2. **`terrain` à exposant WSPD plat ~1,27 sur deux doublements** : seul cas inexpliqué de la campagne, laissé ouvert explicitement (1.10 § 7).
3. **Linéaire vs `n log n` pour le front WSPD à boîtes serrées sur arbre radix binaire** : indécidable par la mesure sous u16 (`n <= 65 535`) ; les deux voies (argument théorique de transport de la preuve d'empilement, ou lever le profil) sont notées hors périmètre v3. La V4, qui vise des dizaines de millions de points, devra trancher.
4. **Choix de `s`** (Q1 de 1.7) : « existe-t-il un `s` minimal admissible au dossier ? » — pas de réponse dans cette tranche ; seule la dépendance `s^1,5` est mesurée. La V4 annonce s = 6/8/10 : l'optimum `rectangles × raffinement` reste à mesurer.
5. **Forme de bloc du non-crédit endpoint pour q3/q4** (Q3 de 1.6) : `z=a` donne `H=0` ponctuellement, mais le test de bloc `qH_min² > (EX)_max` n'est pas monotone (carré) ; masque = théorème ou mécanisme (drapeau de recouvrement) ? La réception de `77320f4` (1.8 § 5.1) établit l'extension ponctuelle avec test de signe, mais la forme **de bloc** n'est pas tranchée ici. Selon la réponse, `relation_frontier` est un champ mort (q2) ou central (q3/q4).
6. **Complétude de `carrier_enumeration_root` après élisions** : l'ABI existe, les gates G11–G13 sont spécifiées, mais « il manque encore une gate prouvant que cette racine désigne le domaine neutre complet » (1.1 § 2.3) — non fermé dans cette tranche.
7. **Héritage de la frontière C** (fin de 1.4 § 10) : théorème énoncé et gravé, implémentation annoncée « prochain commit » avec critère exposant < 2 sur les familles denses — le résultat n'apparaît pas dans les 12 fichiers lus.
8. **Q2 de 1.5 (spans `NONE` supprimés de la continuation)** : la réponse de 1.1 la qualifie (élidable du sous-état, jamais du domaine de lane ; digest = intégrité seulement) mais la forme exacte de la continuation q3/q4 (route v0 redémarrage vs route v1 transfert typé `NONE_CORE_BY_H_NONPOS → CarrierFrontier`) reste à mesurer.
9. **`EdgeCenterShallowCut`** (fallback arrangement 2D pour arêtes denses, 1.3 § 9) : seulement esquissé, commutation « par mesure » (`c_e·m_e`), aucun chiffre dans cette tranche.
10. **Census q2** : la conservation des `shell_spans` est faite mais leur **consommation** par un `BallCensusLedger` (avec `I_B/U_B/BallKey/BallEvent` et niveaux exacts) reste due (1.8 § 5.3) ; de même les « vrais PointId et D=0 » de l'ordre consolidé.
11. **Ambiguïté de chronologie WSPD** : la question 1.7 contient déjà sa propre rétractation (§ 2) ; les deux réponses d'auditeur (1.11, 1.12) traitent la version antérieure, et 1.10 montre que leurs deux causes (cap, scission par population) sont « réelles et mineures » à cap=512 — le cap ne mord pas, la scission coûte 15–28 %.
