### 1.1 NOTE_AUDITEUR_POISSON_CHARGE_CARRIERS_AIGUS_20260815.md (auditeur)

- Question : combien de porteurs aigus (« carriers ») par paire W-vivante sous Poisson homogène de dimension intrinsèque `d` ? Réponse en forme close.
- Région du carrier pour une paire `e={a,b}` de longueur `r` : `||x-a|| <= r`, `||x-b|| <= r`, `(a-x)·(b-x) > 0` = lentille moins la boule diamétrale. Volume `|A_e| = c_d r^d` avec `c_2 = 5*pi/12 - sqrt(3)/2 = 0,4429715352` et `c_3 = pi/4 = 0,7853981634`.
- Indépendance : le fuseau `W_q` est dans la boule diamétrale, la région aiguë strictement dehors — donc comptes indépendants conditionnellement à la paire. Identités gamma : `int P(Poisson(u)<h) du = h`, `int u P(Poisson(u)<h) du = h(h+1)/2`, donc `E[u | paire W-vivante] = (h+1)/2` et `E[#carriers | paire W_q-vivante] = (c_d/v_{q,d}) * (h+1)/2`.
- Total par point : `E[C_q]/E|P| -> s_{d-1} c_d h(h+1) / (4 d v_{q,d}^2)`.
- Chiffres avec `smax=11` (`h_3=9`, `h_4=8`) : q4 en `d=2` : `34,6244` W-vivantes/pt, `5,4924` carriers/paire, `190,170` incidences/pt ; q4 en `d=3` : `139,070` / `29,3350` / `4 079,607`. q3 en `d=3` : `123,796` / `25,7909` / `3 192,815`.
- À `n=30 M` : `5,71 G` incidences (surface) ou `122,4 G` (volume) ; à 16 octets : `~91 Go` / `~1,96 To`. Conclusion : `O(n)` avec cette constante interdit tout catalogue résident de faces ; l'unité de scheduling est le bloc (`count -> preflight -> continuation/sweep -> émission finale`), jamais `bloc -> expansion de toutes les faces -> tri`.
- Sur une nappe exactement plane, le q4 final est vide (dépendance affine) mais les triangles carriers existent : le rang doit être branché tôt pour que le régime surfacique ne paie pas la sweep quaternaire.
- Contre-famille `two_lines` : `Theta(n^2)` ancres q4 vivantes, exactement zéro carrier. Les deux modèles (Poisson et two_lines) doivent rester simultanément verts.

### 1.2 NOTE_AUDITEUR_POISSON_DIMENSION_INTRINSEQUE_20260815.md (auditeur)

- Question : pourquoi `terrain` porte-t-il beaucoup moins d'ancres que `uniform` ? Réponse : `terrain` est un processus de dimension intrinsèque 2 plongé dans `R^3` ; Campbell–Mecke se généralise exactement.
- Théorème : `E|V_q|/E|P| -> C_{q,d} = s_{d-1} h_q / (2 d v_{q,d})` (l'intensité `lambda` s'élimine — résultat de complexité **moyenne par point**, pas pire cas).
- Volumes normalisés des fuseaux (`|ab|=1`) : `v_{2,2} = pi/4`, `v_{3,2} = -sqrt(3)/6 + 2pi/9`, `v_{4,2} = 3pi/8 - sqrt(2)/4 - 3 asin(1/sqrt(3))/4` ; `v_{2,3} = pi/6`, `v_{3,3} = pi(27-4 sqrt(3) pi)/108`, `v_{4,3} = pi(28-9 sqrt(2) pi + 18 sqrt(2) asin(1/sqrt(3)))/96`. En `d=1` : `v_{q,1}=1`, `C_{q,1}=h_q`.
- Tableau des constantes `C_{q,d}` : `d=1` : `10/9/8` ; `d=2` : `20,000 / 34,5267 / 34,6244` ; `d=3` : `40,000 / 123,7962 / 139,0696`. Saut q4 surface→volume : facteur `4,02`.
- Validation : `terrain, n=2000` mesure `35,321` q4/pt, à `2,0 %` de la constante planaire `34,624` ; `uniform` extrapolé (correction de bord en `n^{-1/3}`) donne `136,019`, à `2,2 %` de `139,070`.
- Lentille conditionnelle : parmi les paires W_q-vivantes, `E[N_L] = (R_{q,d} h_q + R_{q,d} - 2)/2` avec `R_{q,d} = vol(L)/vol(W_q)`. Plan : `ell_2 = 2pi/3 - sqrt(3)/2 = 1,228369699`, `R_{4,2}=3,384553256`, `E[N_L]=14,23049` (mesuré `terrain` : `16,60`, à ~17 %). Volume : `ell_3 = 5pi/12`, `R_{4,3}=10,864814574`, `E[N_L]=47,89167` (mesuré `uniform` : `38,94` ; `eight_clusters` : `87,82` = `1,83×` la prédiction, quantifie l'inhomogénéité).
- Conséquence LiDAR : baisser la densité par dix ne change pas au premier ordre le broad phase par point ; ce qui compte est la dimension intrinsèque, les bords, les trous et les paires inter-composantes. Protocole proposé : nappe 2D / volume 3D / lignes 1D / familles croisées, diagnostic par point de dimension locale. Une pente log-log seule ne distingue rien.

### 1.3 NOTE_AUDITEUR_POISSON_VRAIS_SUPPORTS_Q4_20260815.md (auditeur)

- Question : combien de vrais supports q4 positifs (< h intérieurs) sous Poisson homogène dans `R^3` ? Réponse **exacte** via Edelsbrunner–Nikitenko–Reitzner (Adv. Appl. Prob. 49, 2017, doi:10.1017/apr.2017.20) + Blaschke–Petkantschin.
- Théorème : `E[W4_positive(<h)] / E[n] = (3*pi^2/16) * C(h+2,3)`. Pour `h=r4=8` : `= 45*pi^2/2 = 222,066099...` par point.
- Constantes de base : niveau vide `C^3_{3,3} = 3*pi^2/16 = 1,850550825` (3-simplexes critiques de la fonction rayon = tétraèdres de Delaunay bien centrés) ; tous les tétraèdres Delaunay : `D^3_3 = 24*pi^2/35 = 6,767728732` ; fraction bien centrée exactement `35/128 = 27,34375 %`, indépendante de `rho` et du rayon.
- Facteur du niveau `k` : jacobien radial `r^8 dr`, poissonnien `t = rho*nu_3*r^3` ⇒ `I_k/I_0 = C(k+2,2)` donc `E[N_k^+] = (3pi^2/16) C(k+2,2) rho |Omega|` ; somme `sum_{k<h} C(k+2,2) = C(h+2,3)`.
- Décomposition par profondeur (`h=8`) : `k=0..7` donne `1,85 / 5,55 / 11,10 / 18,51 / 27,76 / 38,86 / 51,82 / 66,62` par point. **Le niveau `k=7` seul pèse `36/120 = 30 %`** de la masse ; passer de `h=8` à `h=7` retire 30 %, pas un huitième.
- Cohérence des étages Poisson q4 volumique : `V4_pair_walive/n ~ 139,07`, `W4_positive(<8)/n ~ 222,07`, `C4_carrier/n ~ 4 079,6`. Rapports : `~1,5968` supports positifs par paire W-vivante ; `~18,37` carriers par support positif. Oracle statistique pour détecter duplications d'owner, gateway perdant, fenêtre carrier incomplète.
- À `n=30 M` : `~6,66 milliards` de supports ; ≥ `106 Go` à 16 octets. Architecture imposée : `bloc -> count/preflight -> sélection shallow -> BallKey/SupportKey -> radix/RLE en vague -> fold -> libération`, jamais énumération globale puis tri. Le fold doit être fait **pendant** le flux.
- Portes : tore périodique ou fenêtre intérieure (un cube fini n'est pas le processus stationnaire), rampe sur ≥ 4 tailles, fixtures déterministes (`regular_tetra_q4_positive`, `one_acute_incident_face_q4`, `cube8_shell_plateau`, `two_lines`).
- Limites explicites : ne prédit ni surfaces quasi-2D, ni scanlines/multi-échos, ni plateaux u16, ni le nombre final de fusions après fold HGP.
