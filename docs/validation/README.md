# Validations et artefacts

Ce dossier contient les revues de phase actives et les artefacts bruts lus par les checkers. Les rapports de voies explicitement abandonnées ont été déplacés dans les [archives scientifiques](../archive/README.md), mais leurs JSON et transcripts restent ici lorsque leur chemin stable protège une non-régression.

Pour connaître l'état courant, lire d'abord [PHASE15_PROGRESS.md](PHASE15_PROGRESS.md), puis le [registre des phases](../implementation_status.toml). Un artefact G4 historique n'est jamais, à lui seul, une qualification de la voie produit actuelle.
