# Archive

Ce dossier conserve les documents de conception antérieurs à la refonte **polyèdre-only** d'août 2026.

Ils peuvent contenir :

- une architecture hybride point/hiérarchie ;
- des propositions centrées sur les descripteurs de nœuds ;
- plusieurs voies de publication désormais abandonnées ;
- un contrat géométrique plus détaillé que nécessaire pour le prototype ML ;
- des seuils ou états de concurrence périmés.

## Statut

Les fichiers archivés sont **historiques et non normatifs**. En cas de contradiction, l'ordre d'autorité est :

1. [`../README.md`](../README.md) ;
2. [`../ARCHITECTURE.md`](../ARCHITECTURE.md) ;
3. [`../ENTRAINEMENT.md`](../ENTRAINEMENT.md) ;
4. [`../PROTOCOLE.md`](../PROTOCOLE.md) ;
5. le manuscrit de thèse pour les définitions géométriques.

## Fichiers conservés

| Fichier | Intérêt résiduel |
|---|---|
| `ARCHITECTURE.md` | détails de l'ancienne architecture hybride et du contrat d'incidences |
| `CONTRAT_HGP.md` | schéma d'export géométrique détaillé |
| `DESCRIPTEURS_DE_NOEUD.md` | analyses théoriques des descripteurs fusionnables |
| `RESEARCH_PLAN.md` | historique des premiers work packages |
| `STRATEGIE_PUBLICATION.md` | raisonnement de positionnement antérieur |
| `THEOREMES.md` | énoncés et pistes théoriques à ne pas perdre |

Aucun nouveau développement ne doit être guidé par ces fichiers sans reporter explicitement l'idée dans le corpus principal.
